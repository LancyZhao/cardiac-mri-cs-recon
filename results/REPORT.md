# 实验结果（真实测量值）

数据集：MSD Task02_Heart（心脏 MRI，左心房分割，20 例 `.nii.gz`）

划分：**按病例**划分，train 14 例 / test 6 例；切片 1601 / 670；分辨率 192×192

## 方法学边界（面试可直接引用）

- MSD 数据是**已重建的幅值图**，不是原始多线圈 k 空间。这里做的是 retrospective undersampling（幅值图 FFT 后抽样），没有真实相位与线圈灵敏度信息，绝对 PSNR 偏乐观，**不能与 fastMRI 上的论文数字直接比较**。
- 划分在**病例级**而非切片级。同一病例相邻切片高度相似，按切片随机划分会造成测试集泄漏、指标虚高。
- 欠采样用笛卡尔一维变密度随机（只抽相位编码线，中心保留 ACS），对应临床 2D 序列真正能省的时间；二维随机点采样在 2D 序列里物理不可实现。
- 单次运行、单一 seed，未做多 seed 重复，Dice/PSNR 的置信区间未估计。
